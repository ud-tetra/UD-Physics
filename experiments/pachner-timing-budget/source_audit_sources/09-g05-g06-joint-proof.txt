## G05 restricted-scalar theorem

**EXACT / CONDITIONAL.** For nonzero linear `L` on `U`, a unique `κ` satisfies `I(z)=κ L(z)` for every `z∈U` iff `ker(L|U)⊆ker(I|U)`. Equivalently, the restrictions of the two rows have rank one. Proof: take any `u` with `L(u)≠0`, set `κ=I(u)/L(u)`, and decompose arbitrary `z=[z−L(z)u/L(u)]+L(z)u/L(u)`; the bracket is in `ker L`. Necessity follows by evaluating `I=κL` on the kernel. If `L=0`, the equality is possible only when `I=0` on all of `U` and then `κ` is nonunique. These hypotheses are part of the result, not source selections.

If `U=R^m` with independently variable increments, then `I=(1/2)1·z` and `L=w·z` admit a scalar iff **every** `w_i=w≠0`, with `κ=1/(2w)`. For two modes and `w=(1,2)`, histories `z=(1,0)` and `(0,1)` have the same `I=1/2` but `L=1,2`; row rank is 2. If `w=(3,3)`, `κ=1/6` works on all histories. A law restricting `U` to `z_1=z_2` changes the result: the former unequal weights then admit `κ=1/3` on that restricted line. A source must select both `U` and `w`; choosing them to make a coefficient is an inverse construction.

On a *fixed amplitude* stratum with `L=Σℓ_i φ_i`, the criterion becomes `a_i/2=κℓ_i` on the accessible phase space. Exact witness: `a=(2,3), ℓ=(1,1)`, phases `(1,0),(0,1)` give `L=1` twice but `I=1,3/2`. Restricting to `a=(2,2)` gives `κ=1`; varying the first amplitude from 2 to 4 with the same first phase and same amplitude-blind `L` changes `I` from 1 to 2. This is **NO-GO** for a universal coefficient from that amplitude-blind statistic on the variable-amplitude domain. It does not establish that Q136 is amplitude-blind: the `σ` source-to-O09 map is OPEN. O09's lifted winding information also rules out an endpoint-only statistic on unrestricted winding histories by the earlier audit.

## G06 scale theorem and joint identifiability

**EXACT / CONDITIONAL.** Under O10/O14 and fixed nonzero external `ℏ`, rescale the native mass-like unit `B0→λB0` with `λ>0` while holding `a0,τ0` and dimensionless native histories fixed. Then `A0→λA0` and `η_A→λη_A`; O09's dimensionless `I` and every native `κ=I/L` remain unchanged. Thus the native action-history theorem cannot determine a numerical G06 ratio. The proof is an exact group action on the declared input family. An independently justified unit anchor or physical phase map can break it; a native count alone cannot.

For positive monomial dimensional anchors with exponent rows `W` in `(M,L,T)`, the action exponent `v=(1,2,−1)` is identifiable from their known absolute values **iff** `v` is in the row span of `W` (assuming no other unknown dimensionless calibration factors). Proof: in logarithmic unit coordinates, measurements give `Wu`; `v·u` is constant on each solution fiber exactly when `v` annihilates `ker W`, equivalently `v∈row(W)`. Length and time rows alone fail rank 2→3; energy `(1,2,−2)` plus time `(0,0,1)` sum to `v`. This recovers the earlier upstream anchor theorem with a separate exact rank check. It certifies *identifiability if the anchors exist and refer to the same carrier*, not an observed anchor or a value for `η_A`.

**Joint consequence:** if a validated physical phase map has `χ=η_A I` and a restricted scalar alias has `I=κL`, then `χ/L=β=η_A κ` for `L≠0`. A β-only readout identifies only the product: `(η_A,κ)=(2,1)` and `(1,2)` both give β=2. If `I` is independently read from the same native lifted history, `κ=I/L` can be tested; if the physical phase map is independently justified and `I≠0`, `η_A=χ/I` becomes identifiable. This is a **conditional measurement contract**. Neither the physical phase map nor a same-carrier action anchor was supplied. The exposed candidate `η_A=2` must not be used to choose `κ`, weights, phase convention, or anchor.
