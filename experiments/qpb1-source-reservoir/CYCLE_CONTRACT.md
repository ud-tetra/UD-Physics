**PROPOSED / NOT EXECUTED / UNSCORED.** Mathematical resource accounting for the conditional model; no admitted physical apparatus, quantum implementation or universal unit anchor.

## One declared cycle

1. Establish the original unit-metric carrier and address only the sign-isotypic rank2 plane. Record all spectator/harmonic support; do not treat it as erased.
2. Present a fresh matched source with frozen incoming support, phase and calibration records. Unit support is an input hypothesis, not a result of the transfer.
3. Apply the independently specified envelope; record its area and source/target phase relation. For exact matched area pi/2, the addressed states swap. Close the coupling afterward.
4. Read target-plane population using a declared readout map. Preserve the outgoing reservoir state. Supply physical energy measurements separately from normalized support.
5. Account for source refresh, target removal where applicable, the controller state and outgoing records. A claimed repeatable cycle must specify how every changed resource is restored or exported.

## Checks before a physical evaluation

Validate carrier reduction and port correspondence, clock and actuator dynamics, source matching, positive energy, gate loading and isolation. State which quantities are chosen controls and which are source-derived. Calibrate pulse area without using the candidate eta. Provide coverage for old-state norm, detuning, loss, actuator error and readout uncertainty.

Use the empty-target quadratic pulse-error bound only for an evidenced empty addressed target. For occupied targets use the interference-sensitive bound or a stronger supported estimate. The detuning formula is a best-over-time limit in the constant-coupling toy model; it is not a fixed-time tolerance certificate.

Quantum comparison additionally requires an independent energy operator and physical correspondence for the population readout. A successful classical swap is the baseline. A single full-transfer observation has eta aliases; freeze a parameter domain and multiple discriminating pulse points before independent data exposure. No thresholds, precision claims or scored outcome are invented here.
