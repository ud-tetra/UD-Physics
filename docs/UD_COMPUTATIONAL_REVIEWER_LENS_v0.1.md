# UD Computational Reviewer Lens v0.1 — primary task and claim firewall

**Mission:** Review UD primarily as a finite computational geometry, rendering and predictive simulation framework. Do NOT presume that it asserts a literal digital universe, an existing theory of everything, a physical K4 substrate or an established physical law. Read [UD-MISSION-002 v0.2](../docs/proposals/UD-MISSION-002-v0.2-authorized-implementation.md) as the authorized mission direction.

## Source trust
Retrieve and pin the actual UD and UD-Physics repository files and source claims before grading them. Distinguish accepted source, development PR, exact algebra, simulation result, fit, physical candidate and independently measured evidence. Preserve old no-go scopes and allow changed assumptions only as named new branches. Do not cite a partner LLM summary as source verification.

## Computational review contract
For each question, identify: carrier and topology, coefficient/state and units, discretization and geometric realization, metric and normalization, evolution operator, initial/boundary conditions, observable and rendering/readout; proof/replay scope; conservation error, numerical convergence, conditioning, mesh sensitivity, complexity and reproducibility; comparison against analytic/FEM/DEC/finite-volume or relevant null; held-out prediction if a physical bridge is claimed.

**Technical corrections:** K4 is a 3-simplex, not a voxel; partial^2=0 is topology, not a complete continuity law; metric-skew continuous flow does not itself define a symplectic *integrator*; 192 is a stipulated finite exposure cardinality, not necessarily an orbit/particle list; discrete structure does not remove constitutive and calibration choices.

**Review modes:**
- ALGEBRA: assess exact claims and proof, identify assumptions.
- SIMULATION: evaluate algorithm, baseline, sensitivity, conservation, benchmark and rendering integrity.
- BRIDGE: evaluate SI units/readout/calibration, uncertainty, target exposure, competing physics and independent falsification.
- ONTOLOGY: only assess literal substrate claims when explicitly advanced, never assume them from the model description.

**Ready-to-report output:** RESULT/STATUS, source pins, exact assumptions, passed and failed controls, generalization boundary, priority next discriminant. Physical Promotion = 0 absent applicable independent correspondence receipt.

**Suggested invitation:** “Review the correctness, numerical stability and practical predictive value of this finite tetrahedral modeling architecture. Do not assume a literal tetrahedral universe is claimed. Point out specific mathematical and empirical errors where they actually occur.”
