## Minimal contract

The [free K4 root audit](../geometry-root-persistence/README.md) shows that a one-hot amplitude seed loses a unique root under free incidence flow. Introduce a fixed four-component contact register `r=e0` that remains outside the evolving vertex/edge state. With ascending K4 incidence `B`, unit metric, signed `x∈R4`, `y∈R6`, dimensionless `s`, and **assumed** `gamma>=0`, define

`x'=-B y,    y'=B^T(x-r)-gamma y`.

For a fixed `r`, the shifted contact energy `E_r=(||x-r||²+||y||²)/2` obeys `E_r'=-gamma ||y||²`. The contact is an affine bias `-B^T r` in the edge equation, and `gamma y` is a passive loss term. Neither occurs in the free Q166 generator. At `x=r,y=0`, the state is exactly stationary for every `gamma>=0`: retaining the root is supplied by the fixed contact register, not generated by free flow.

For the native unshifted quadratic stock `S=||x||²+||y||²`, the same equations give

`S'=2 r·x' - 2 gamma ||y||² = -2 y·B^T r - 2 gamma ||y||²`.

The Q166 local current `F_ie=2 B_ie x_i y_e` still accounts for the internal vertex-edge exchange. The residual `-2 y·B^T r` is **contact work on native stock**, and `-2 gamma ||y||²` is a separate loss. Q170-style accounting must explicitly include these boundary/source terms; applying closed stock conservation to this biased model would be incorrect. For a time-dependent continuous register `r(s)`, `E_r'=-gamma||y||²-(x-r)·r'`. At an instantaneous register switch, with `x,y` unchanged, the jump is `Delta E= -x·(r_new-r_old)+(||r_new||²-||r_old||²)/2`. Equal-norm one-hot labels simplify it to `-x·Delta r`.
